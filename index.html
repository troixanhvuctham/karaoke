🎤 Hát Karaoke

Tuỳ chọn: thêm YouTube API key (miễn phí) để hiện kết quả ngay trong trang. Không có key thì trang tự mở YouTube.
  1. Vào Google Cloud Console, tạo project rồi bấm Enable (YouTube Data API v3).
  2. Vào Credentials → Create credentials → API key, copy key.
  3. Dán vào ô dưới đây. Key chỉ lưu trên trình duyệt của máy này.
